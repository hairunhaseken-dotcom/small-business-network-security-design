# Network Security Policy

## 1. Access Control
Users should only access systems and data required for their
job responsibilities. Administrative access must be restricted.

## 2. Guest Network
Guest devices should have internet access only and must not
access employee computers, servers, or management interfaces.

## 3. Wireless Security
Use WPA3 where supported, strong authentication, and separate
guest access. Disable insecure legacy configurations.

## 4. Multi-Factor Authentication
MFA should be required for administrative accounts and
remote access wherever supported.

## 5. Monitoring and Logging
Record relevant firewall events, authentication failures,
administrative activity, and important security alerts.
Protect logs against unauthorised access.

## 6. Patch Management
Apply security updates regularly and prioritise critical
vulnerabilities according to risk.

## 7. Backup and Recovery
Maintain encrypted backups, restrict backup access, and
test restoration procedures regularly.

## 8. Incident Response
Document how to report incidents, contain affected devices,
preserve relevant evidence, and restore services safely.
